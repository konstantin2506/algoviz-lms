# algoviz-lms
AlgoViz is a web application (LMS) designed for students and instructors of Algorithms and Data Structures (ADS) courses.

The project addresses the static nature of classic textbooks and the fragmentation of existing visualizers. Our platform combines an interactive data structure builder, step-by-step algorithm animation, and a comprehensive testing module with a grading system.


### Понять и собрать приложение:
```bash
    docker compose up --build -d
```
